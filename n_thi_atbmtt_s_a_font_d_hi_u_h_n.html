Mẹo 2 · Tìm khóa giải mã RSA bằng TABLE

Tìm nghịch đảo a-1 mod n

Hiểu nôm na: Trong chia dư không có phép chia thông thường, nên tìm a-1 mod n nghĩa là tìm số d sao cho (a × d) chia n dư 1.

Thay vì kẻ bảng Euclid mở rộng dễ nhầm dấu, hãy dùng chế độ lập bảng TABLE trên Casio để dò nghiệm:

MENU 8 (570: MODE 7) f(X) = (nX + 1) ÷ a Start 0, End 25, Step 1

Lướt cột f(X): thấy số nào nguyên đẹp (không có dấu phẩy thập phân) thì đó chính là đáp án! (Nếu kết quả lớn hơn n thì lấy nó mod n). Nếu GCD(a, n) ≠ 1 thì vô nghiệm.

Mẹo 3 · Bấm bit Nhị phân & Hex

Chế độ BASE-N (TinyDES, MD5 thu nhỏ)

Nhớ nhanh phép XOR (⊕): Hai bit giống nhau ra 0 (0⊕0=0, 1⊕1=0); hai bit khác nhau ra 1 (0⊕1=1, 1⊕0=1).

Chuyển máy tính sang chế độ hệ cơ số để đổi nhanh giữa HEX (hệ 16) và BIN (nhị phân), kèm phép xor, and, or:

fx-570: MODE 4 fx-580: MENU 3 880BTG: HOME → Base-N

Nhấn OPTN (hoặc SHIFT+3 trên 570) để gọi xor, and, or. Khi gặp phép quay trái <<< s trên 8 bit (MD5/SHA thu nhỏ), viết đủ 8 bit rồi cắt s bit đầu chuyển xuống cuối!
